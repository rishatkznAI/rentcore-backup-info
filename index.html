Локальный инструмент владельца системы

rentCore Backup

rentCore Backup предназначен для зашифрованного резервного копирования и восстановления rentCore владельцем системы с использованием его Google Диска.

Инструмент работает на компьютере Ubuntu и использует Google OAuth и Google Drive API. База SQLite, uploads и выбранные конфигурации шифруются restic до передачи в Google Диск. Для восстановления нужны доступ к репозиторию и отдельно сохранённый пароль restic.

Текущее разрешение — https://www.googleapis.com/auth/drive. Оно позволяет управлять всеми файлами Google Диска аккаунта. Работа инструмента ограничена отдельной приватной папкой его локальной конфигурацией; само OAuth-разрешение такой границы не устанавливает.

Google Drive API используется для чтения, создания, изменения и удаления объектов зашифрованного репозитория, проверки его целостности и восстановления. Приложение предназначено только для личного использования владельцем.
